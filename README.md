# Copiloto Antifadiga – Protótipo 1

Mockup 3D interativo do dispositivo antifadiga: uma câmera no painel que acompanha os olhos do motorista e avisa por voz, em 3 níveis, antes do microssono. As imagens são processadas no próprio aparelho, sem gravação e sem envio.

**Acesse:** https://bthiago09.github.io/copiloto-antifadiga/

## Como usar
- Arraste para girar e role para aproximar.
- Toque nos números para conhecer cada parte do aparelho.
- **T** abre/fecha a tampa de privacidade · **N** liga o modo noite · **G** gira o aparelho · **← →** troca a parte.
- Na parte 4 (alto-falante), ouça os 3 níveis de alerta. O botão âmbar no volante é o "Estou Bem".
