# Copiloto Antifadiga – Protótipos

Mockup 3D interativo do dispositivo antifadiga: uma câmera no painel que acompanha os olhos do motorista e avisa por voz, em 3 níveis, antes do microssono. As imagens são processadas no próprio aparelho, sem gravação e sem envio.

- **Protótipo 1 – Dispositivo no painel (3D):** https://bthiago09.github.io/copiloto-antifadiga/
- **Protótipo 2 – Simulador de estrada com detecção dos olhos:** https://bthiago09.github.io/copiloto-antifadiga/simulador/

## Como usar o Protótipo 1
- Arraste para girar e role para aproximar.
- Toque nos números para conhecer cada parte do aparelho.
- **T** abre/fecha a tampa de privacidade · **N** liga o modo noite · **G** gira o aparelho · **← →** troca a parte.
- Na parte 4 (alto-falante), ouça os 3 níveis de alerta. O botão âmbar no volante é o "Estou Bem".

## Como usar o Protótipo 2
- Clique em **Iniciar com a câmera** e permita o acesso. Para usar a câmera do celular, conecte-o como webcam (DroidCam ou Vincular ao Celular) e escolha-o na lista, ou abra o link direto no celular.
- Olhe para a estrada por 3 segundos para calibrar.
- **← →** ou **A D** trocam de faixa. Feche os olhos por alguns segundos para ver os alertas.
- **Espaço** = Estou Bem · **P** pausa · **Segure C** simula olhos fechados (útil se a câmera falhar na apresentação).
- A imagem da câmera é processada no próprio navegador e nunca é gravada nem enviada.
